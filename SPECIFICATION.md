## 8. On-Screen Mobile Debugging Framework (The Lens)

To overcome the limitations of traditional mobile debugging (e.g., USB cables, platform-specific inspectors), we will use an in-app, on-screen console for real-time log inspection on mobile devices.

- **Activation**: The on-screen console will be activated *only* for authorized developer accounts.
- **Implementation**: A dedicated React component (`OnScreenConsole.tsx`) will be responsible for displaying the logs.
- **Logic**: The application will capture `console.log`, `console.error`, etc., and pipe them to the on-screen console if the current user is a designated debugger.
- **Security**: The list of authorized debugger emails will be managed securely and should not be hardcoded in client-facing code in a production environment.
